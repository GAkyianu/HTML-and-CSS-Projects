# One‑Page Website Project

This project is a simple, responsive one‑page website built using **HTML**, **CSS**, and **JavaScript**.  
It was originally created during the HTML & CSS course and later enhanced with JavaScript by adding a **lightbox image gallery**.

---

## 📌 Features

- Clean, single‑page layout  
- Responsive design  
- Image gallery with thumbnails  
- JavaScript‑powered **lightbox modal** for enlarged images  
- Two image sizes:
  - **smallsize_XX.png** → used as thumbnails  
  - **fullsize_XX.png** → displayed inside the lightbox  

---

## 🖼️ Lightbox Functionality

The JavaScript file (`one_page_website.js`) creates a modal image viewer that:

- Opens when a thumbnail is clicked  
- Displays the full‑size version of the image  
- Allows the user to close the modal by clicking outside the image or pressing the close button  

This provides a clean and interactive way to view images without leaving the page.

---

## 🚀 How to Run the Project

1. Open the folder **One‑Page Website**
2. Double‑click `one_page_website.html`
3. The website will open in your browser
4. Click any thumbnail to view the lightbox
